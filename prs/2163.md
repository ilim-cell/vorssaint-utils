## Summary

Before, dragging the timer ruler changes the selected duration in discrete ticks, so a smooth trackpad movement can appear to jump between values.

After, the ruler would follow the live pointer position with a continuous visual transition, settle on the same supported duration values, and round the scrubber needle’s corners. The interaction model, easing curve, reduced-motion behavior, and accessibility announcements still need to be specified before implementation.
