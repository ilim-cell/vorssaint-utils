## Summary

Before, macOS Launchpad provided a single searchable grid for installed applications. On newer macOS versions that entry point is no longer available, so users must rely on Spotlight or Finder.

After, this branch would need to provide an opt-in Launchpad-style view with application discovery, search, ordering, folders, and a launch interaction. It is not ready for implementation: deletion semantics, the trackpad gesture, Dock and hotkey entry points, and migration of an existing Launchpad layout all require product and permission decisions first.
