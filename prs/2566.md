## Summary

Before, App Updates can already include Homebrew updates while Homebrew also has a dedicated updater surface. That duplicates the update entry point and makes it unclear which surface owns Homebrew status and actions.

After, Homebrew update discovery and installation would have one clear owner, with the other surface either redirected or removed while preserving existing package-management actions. The compatibility route, progress/log presentation, missing-Homebrew behavior, and settings migration must be decided before implementation.
