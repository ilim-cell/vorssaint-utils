## Summary

Before, reopening the Dynamic Island either restores the last view indefinitely or always opens a configured view. The first can be distracting when switching tasks; the second makes repetitive actions require extra navigation.

After, a configurable timeout would restore the last view only when it was visited recently, then fall back to a selected default view after the timeout expires. The preference UI, time source, behavior across launches, and interaction with visible live activities must be defined before implementation.
