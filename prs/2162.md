## Summary

Before, the Dynamic Island can pin only the existing music, battery, or empty idle states. That leaves useful states such as Focus unavailable when no transient activity is running.

After, users would be able to choose additional idle content, with a deterministic priority order and an explicit “none” option. The issue is not ready for implementation until the state catalog, preference storage, compact layout rules, and interaction when multiple states are available are defined.
