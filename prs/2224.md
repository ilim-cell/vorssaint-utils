## Summary

Before, the Dynamic Island quick panel exposes only built-in actions.

After, users would be able to add a named macOS Shortcut, choose an SF Symbol, and run it from the quick panel or Explore view through `shortcuts run`. The feature still needs a persisted model, validation for missing or renamed shortcuts, explicit execution error reporting, permission handling, localization, and a removal/editing workflow before implementation.

- Shortcuts CLI execution and failure handling were not verified.
