## Summary

Before, Settings sidebar icons used the sidebar tint for unselected rows. With the macOS accent color set to multicolor, a sidebar containing many tools could show low-contrast blue icons and make the labels harder to scan.

After, every sidebar icon uses the system-defined `primary` color. The existing selected-row background and navigation behavior remain unchanged; this is a presentation-only change to the icon foreground and does not change the sidebar catalog, feature availability, or settings destinations.
