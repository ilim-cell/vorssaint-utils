## Summary

Before, the compact Dynamic Island timer used the plain `timer` SF Symbol whenever a countdown was idle. That mark did not communicate that the timer has a measurable progress state and did not match the circular treatment used by macOS.

After, an idle countdown uses `timer.circle`. Completed timers still use `checkmark.circle`, paused timers still use `pause.circle`, and stopwatches still use `stopwatch`; this change is limited to the idle countdown branch and does not alter timer values, layout measurement, or interaction.
